## 🚀 How to Run Locally

You do not need any package managers or local servers to view your website:

1. Simply double-click `index.html` to open it in your browser (Chrome, Edge, Firefox, Brave, Safari, etc.).
2. Or open the folder in VS Code / Antigravity and use **Live Server** extension if desired.

## 🌐 How to Publish for Free on GitHub Pages

You can host your portfolio for free under your personal GitHub URL: `https://udaypatil-collapse.github.io`!

1. Create a new repository on your GitHub account (`udaypatil-collapse`) named:
   ```
   udaypatil-collapse.github.io
   ```
   *(Or give it any name, such as `portfolio`)*.
2. Push this folder's contents (`index.html`, `style.css`, `script.js`, `profile.jpg`) to the repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release for Uday Patil"
   git branch -M main
   git remote add origin https://github.com/udaypatil-collapse/udaypatil-collapse.github.io.git
   git push -u origin main
   ```
3. In GitHub, go to **Settings** > **Pages** > ensure the source is set to `main` branch.
4. Your website will be live worldwide in seconds!

## ✏️ Customization Notes

- **LinkedIn URL**: When your customized LinkedIn profile link is ready, update the `href` attribute for `id="connectLinkedInBtn"` and `id="footerLinkedInBtn"` in `index.html`.
- **Resume File**: Place your resume PDF in this folder named `resume.pdf` and link it to the Download Resume buttons.
- **Current Semester**: Adjust the text in the Education card inside `index.html` (e.g., `Semester IV` or `Semester V`).
